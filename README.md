# 🏥 منظومة قائمة أدوية التأمين الصحي (Insurance Drug List)

بوابة إلكترونية تفاعلية وسريعة ومصممة خصيصاً لمساعدة الصيادلة والأطباء في الاستعلام السريع والمباشر عن أدوية ومستلزمات قائمة التأمين الصحي، وتحديد السلطة الوصفية المعتمدة لكل صنف دوائي بدقة وسهولة.

---

## 🌟 مميزات المنظومة

- **🔍 بحث فوري وذكي**: بحث متعدد المعايير بالمادة الفعالة (Generic Name)، أو الاسم التجاري (Brand/Trade Name)، أو الشكل الصيدلي، أو رقم الكود الدوائي.
- **🏷️ فلترة القوائم الرسمية**:
  - أدوية مجانية (33 مجموعة علاجية رئيسية + لجان عليا للأورام والدواء).
  - أدوية تجارية (Commercial Drugs).
  - أدوية خاصة (Special Drugs).
- **📋 تمييز السلطات الوصفية**:
  - `GP`: ممارس عام (General Practitioner).
  - `SP`: أخصائي (Specialist).
  - `CON`: استشاري (Consultant).
  - `اللجان العليا`: لجان الأورام، التصلب المتعدد MS، أمراض القلب، واللجنة العليا للدواء.
- **📱 واجهة مستخدم حديثة بنمط iOS**:
  - قائمة منسدلة أنيقة منبثقة بنمط iOS لاختيار المجموعات الدوائية الـ 35 مع تصنيف إنجليزي رئيسي وترجمة عربية توضيحية.
  - تصميم داكن عصري (Dark Glassmorphism) مريح للعين أثناء العمل الميداني.
  - تصميم متجاوب 100% يعمل بسلاسة فائقة على شاشات الهواتف المحمولة والأجهزة اللوحية والكمبيوتر.
- **⚡ تشغيل فوري بدون خادم (Serverless & Offline-Ready)**:
  - يعمل الموقع مباشرة بمجرد فتح ملف `index.html` في أي متصفح دون الحاجة لتثبيت برامج أو اتصال بقاعدة بيانات خارجية.

## 🚀 طريقة التشغيل

1. **التشغيل المباشر**:
   - قم بتحميل أو استنساخ المستودع (Clone).
   - انقر نقراً مزدوجاً على ملف `index.html` ليفتح مباشرة في المتصفح.

2. **عبر GitHub Pages (اختياري)**:
   - يمكن تفعيل GitHub Pages من إعدادات المستودع (Settings -> Pages) ليصبح متاحاً كرابط مباشر لكافة أفراد الفريق الطبي على مدار الساعة.
